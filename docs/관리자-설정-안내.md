## 구조 한눈에 보기 (모두 무료, 결제수단 등록 없음) — 서학동성당과 같은 구조

| 무엇을 | 어디에 |
|---|---|
| 사이트 실행 | **Cloudflare Workers** (`src/worker.js` + 화면 파일 `public/`) |
| 공지·주보·갤러리·본당 일정·접속 팝업·알림함·알림 구독자·관리자 명단·오늘의 말씀 | **Cloudflare D1** 데이터베이스 `yongmeori-church` (표 구조: `migrations/`) |
| 사진 파일 | 이 GitHub 저장소 `public/images/` (새로 올린 사진은 `public/images/uploads/연도/`, 사진 정보는 D1에) |
| 관리자 로그인 | 구글 로그인 (Firebase Authentication, 무료) |
| 휴대폰 알림 | Firebase Cloud Messaging (무료) |
| 오늘의 말씀 자동 갱신 | 매일 00:00 GitHub Actions가 서버를 호출 → 서버가 가톨릭굿뉴스에서 읽어 D1에 저장 (실패하면 GitHub가 메일로 알려줌) |
| 오시는 길 지도 | 카카오 지도 (용머리성당 + 전주 시내 성당 30여 곳 표시) + 네이버·카카오·구글 지도 열기 버튼 |

- 글은 저장하면 **바로** 홈페이지에 반영됩니다.
- 사진은 저장소에 커밋되고 30초~1분 뒤 정식으로 배포되지만, 그 사이에도 서버가 GitHub에서 직접 읽어 **바로** 보여줍니다.
- D1 무료 한도(하루 읽기 500만·쓰기 10만, 5GB)를 넘어도 요금이 나가지 않고 오류만 납니다.
- 예전 주보 222장(다음카페에 있던 것)은 줄여서(약 51MB) 이 저장소 `public/images/uploads/연도/bulletin-날짜-면.jpg`로 옮겼습니다.
  다음카페 글이 지워져도 주보는 계속 보입니다.
- 매년 돌아오는 축일(주보성인 축일 등)과 공휴일은 `public/index.html` 안에 그대로 있습니다 (설날·추석은 해마다 추가).

## 한 번만 해두는 설정

### A. 서버 비밀값 (Cloudflare 대시보드 → Workers & Pages → `yongmeori-catholic` (주소가 `...workers.dev`인 것) → Settings → Variables and Secrets)

| 이름 | 무엇 | 상태 |
|---|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | Firebase 서비스 계정 키 JSON (알림 발송용) | 설정됨 |
| `CRON_SECRET` | 오늘의 말씀 자동 갱신 암호 (GitHub Actions 비밀값 `CRON_SECRET`과 같은 값) | 설정됨 |
| `GITHUB_TOKEN` | 관리자 페이지에서 사진을 저장소에 저장할 GitHub 토큰 | **직접 만들어 넣어야 함 ↓** |

**GITHUB_TOKEN 만드는 법 (이 저장소에만 쓸 수 있는 토큰)**
1. https://github.com/settings/personal-access-tokens/new
2. Token name: `yongmeori-worker`, Expiration: 고를 수 있는 가장 긴 기간
3. Repository access: **Only select repositories** → `YONGMEORI-CATHOLIC`
4. Permissions → **＋ Add permissions** → **Contents** 선택 → **Read and write**
5. **Generate token** → 나오는 `github_pat_...` 복사
6. 위 Cloudflare 화면에서 **Add** → Key `GITHUB_TOKEN`, Value 붙여넣기, **Secret 체크** → **Add variable and deploy**

### B. 자동 배포 연결 (코드·사진이 저장소에 올라가면 자동으로 사이트에 반영)

같은 화면 **Settings → Build → Git repository → Connect**
→ 저장소 `YONGMEORI-CATHOLIC`, 브랜치 `main`, Build command 비워둠, Deploy command `npx wrangler deploy` → **Connect**

### C. 카카오 지도 도메인 등록

https://developers.kakao.com → 내 애플리케이션 → 용머리성당 앱 → **앱 설정 → 플랫폼 → Web → 사이트 도메인**에
`https://yongmeori-catholic.jangsangyun0310.workers.dev` 추가 → 저장
(등록 전에는 지도 칸이 회색이고, 아래 지도 열기 버튼만 동작합니다)

### D. Firebase (이미 설정됨)
- Authentication → 승인된 도메인에 새 주소 추가 완료
- Firestore는 더 이상 쓰지 않습니다 (예전 데이터는 모두 D1으로 옮김)

## 개발·배포 명령 (C:\project 에서)

| 명령 | 하는 일 |
|---|---|
| `npm test` | 서버 테스트 (로컬 D1 + 가짜 구글/GitHub) |
| `npm run test:browser` | 실제 브라우저로 홈페이지·관리자 화면 테스트 (결과 화면은 `test-results/`) |
| `npm run dev` | 내 컴퓨터에서 사이트 띄워보기 |
| `npm run deploy` | D1 표 구조 변경 적용 + 사이트 배포 |

표 구조를 바꿀 때는 `migrations/0002_....sql` 처럼 새 파일을 추가하고 `npm run db:migrate:remote` 로 적용합니다.

## 평소 쓰는 법 (관리자분들께 알려드릴 내용)

- 홈페이지 오른쪽 아래 **"관리자"** 버튼을 누르고 구글 계정으로 로그인
- 저장하면 **바로** 홈페이지에 반영됩니다
- 다른 관리자는 대표 관리자가 **관리자 명단**에서 지메일 주소를 추가하면 같은 방법으로 쓸 수 있습니다
- 카카오톡 안에서 열면 구글 로그인이 안 될 수 있으니, 크롬/삼성인터넷/사파리로 여세요
- 사진은 휴대폰에서 고르면 자동으로 크기를 줄여서 올라갑니다
- 공지 날짜 칸에는 "2026.09.20"뿐 아니라 "상시 모집", "접수마감 2026.09.20" 같은 문구도 쓸 수 있습니다
