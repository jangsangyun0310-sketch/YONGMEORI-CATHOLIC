# 용머리성당 홈페이지 — 관리자 페이지 설정 안내

관리자는 **구글(지메일) 계정으로 로그인**해서 공지·주보·갤러리·본당 일정·팝업·알림을 관리합니다.
글과 사진은 GitHub 저장소에 저장되고, 홈페이지(GitHub Pages)는 지금 주소 그대로 유지됩니다.

- 홈페이지 주소(변경 없음): `https://jangsangyun0310-sketch.github.io/YONGMEORI-CATHOLIC/`
- 관리자 페이지 주소(새로 만듦): `https://yongmeori-catholic.pages.dev/admin/`

> 왜 관리자 페이지만 주소가 다른가요?
> 저장·사진 업로드·알림 발송은 서버 기능이 필요한데 GitHub Pages는 서버 기능이 없습니다.
> 그래서 같은 저장소를 Cloudflare Pages에도 연결해 관리자 페이지만 거기서 돌리고,
> 홈페이지 주소는 그대로 둬서 이미 나눠드린 링크와 홈 화면 설치가 깨지지 않게 했습니다.

아래 설정은 **한 번만** 하면 됩니다. 서학동성당 때와 같은 순서입니다.

---

## A. GitHub 토큰 만들기 (관리자 페이지가 저장소에 글/사진을 저장할 때 씀)

서학동성당 때 만든 토큰(`seohakdong admin`)이 **repo 권한**이면 그대로 써도 됩니다 (같은 계정의 모든 저장소에 적용됨).
새로 만들려면:

1. github.com 에 `jangsangyun0310-sketch` 계정으로 로그인
2. 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 맨 아래 **Developer settings**
3. **Personal access tokens → Tokens (classic)** → **Generate new token (classic)**
4. 아래처럼 채우기
   - Note: `yongmeori admin`
   - Expiration: **No expiration**
   - 체크: **repo** (맨 위 항목 하나만)
5. 맨 아래 **Generate token** → 나오는 `ghp_...` 글자를 복사해 둡니다 (이 화면을 벗어나면 다시 못 봅니다)

## B. Cloudflare Pages 만들기

1. https://dash.cloudflare.com 로그인 (서학동성당 때 만든 계정)
2. 왼쪽 **Workers & Pages** → **Create** → **Pages** 탭 → **Connect to Git**
3. 저장소 **YONGMEORI-CATHOLIC** 선택 → **Begin setup**
4. 아래처럼 채우기
   - Project name: **`yongmeori-catholic`** ← 이 이름 그대로 (관리자 페이지 주소가 이 이름으로 정해집니다.
     다른 이름을 쓰면 `push-config.js`의 `ADMIN_URL`을 그 주소로 바꿔야 합니다)
   - Production branch: `main`
   - Framework preset: **None**
   - Build command: **비워두기**
   - Build output directory: **비워두기** (또는 `/`)
5. **Save and Deploy** → 1~2분 뒤 배포 완료
6. 프로젝트 → **Settings** → **Variables and Secrets** → **Add** 로 두 개 추가 (둘 다 Type: **Secret**)
   | 이름 | 값 |
   |---|---|
   | `GITHUB_TOKEN` | A의 `ghp_...` |
   | `FIREBASE_SERVICE_ACCOUNT` | 컴퓨터의 `C:\project\scripts\serviceAccountKey.json` 파일을 메모장으로 열어 **내용 전체** 복사해 붙여넣기 |

   ⚠ 이름을 붙여넣을 때 **앞뒤에 빈칸이 들어가지 않게** 주의하세요. 서학동성당 때 빈칸 때문에 변수가 안 읽혀서 한참 헤맸습니다.
7. **Deployments** 탭 → 맨 위 배포의 `…` → **Retry deployment** (환경변수를 적용하려면 한 번 다시 배포해야 합니다)
8. 확인: 브라우저에서 `https://yongmeori-catholic.pages.dev/api/health` 를 열었을 때
   `"GITHUB_TOKEN":true,"FIREBASE_SERVICE_ACCOUNT":true` 로 나오면 됩니다. `false`가 있으면 6~7번을 다시 확인하세요.

## C. Firebase 콘솔 설정 (https://console.firebase.google.com → yongmeori-church)

1. **Authentication** → **Sign-in method** 탭 → **새 제공업체 추가** → **Google** → 사용 설정 켜기 → 프로젝트 지원 이메일 선택 → **저장**
2. **Authentication** → **Settings** 탭 → **승인된 도메인** → **도메인 추가** 로 두 개 추가
   - `yongmeori-catholic.pages.dev` (관리자 로그인용)
   - `jangsangyun0310-sketch.github.io` (홈페이지에서 관리자에게만 "관리" 버튼을 보여주기 위해)
3. **Firestore Database** → **규칙** 탭 → 기존 내용을 모두 지우고 `C:\project\firestore.rules` 파일 내용을 **통째로** 붙여넣기 → **게시**

1. `https://yongmeori-catholic.pages.dev/admin/` 접속 → **구글 계정으로 로그인** → `jangsangyun0310@gmail.com` 으로 로그인
2. "무엇을 하시겠어요?" 화면이 나오면 성공
3. **공지사항**에 들어가 목록이 보이면 GitHub 연결도 된 것입니다
4. **관리자 명단**에서 다른 관리자분들의 지메일 주소를 추가하면, 그분들도 같은 방법으로 로그인해서 쓸 수 있습니다

## 평소 쓰는 법 (관리자분들께 알려드릴 내용)

- 홈페이지 맨 아래 작은 글자 **"관리자"** 를 누르고 구글 계정으로 로그인
- 저장하면 **1~2분 뒤** 홈페이지에 반영됩니다 (GitHub Pages가 다시 배포하는 시간)
- 카카오톡 안에서 열면 구글 로그인이 안 될 수 있으니, 크롬/삼성인터넷/사파리로 여세요
- 사진은 휴대폰에서 고르면 자동으로 크기를 줄여서 올라갑니다

| 항목 | 홈페이지에서 보이는 곳 | 저장되는 파일 |
